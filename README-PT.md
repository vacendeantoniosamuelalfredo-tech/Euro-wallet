# ATLÂNTICO EUROPA — SIGNATURE V10

Frontend responsivo para telemóvel e computador.

## Conteúdo
- `index.html` — interface e interações do frontend
- `familia-login.jpg` — imagem de entrada
- `titular-victor.jpg` — imagem de perfil

## Abrir
Mantém os três ficheiros na mesma pasta e abre `index.html` num navegador.

As etapas de processamento e o código de teste pertencem ao frontend. Autenticação bancária real, dados reais de saldo/movimentos e operações financeiras exigem backend e integrações autorizadas. As operações bloqueadas mostram “Acesso restrito”.
